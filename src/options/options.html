GitLab instances

gitlab.com works out of the box. Add a self-managed instance by its address, for example https://gitlab.example.com. Firefox asks for access to that site.

Instance Access Personal access token (optional)

Authentication

By default the add-on uses your existing GitLab sign-in in this browser. No token is needed. Comments are posted as you.

Set a personal access token (scope api) only if your instance blocks session access to the API. Tokens are stored in this browser profile only and are sent only to their instance.
