Authentication

By default the add-on uses your existing GitLab sign-in in this browser. No token is needed. Comments are posted as you.

Set a personal access token (scope api) only if your instance blocks session access to the API. Tokens are stored in this browser profile only, are sent only to their instance, and are accepted only for https instances.
